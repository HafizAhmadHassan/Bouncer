# Bouncer
*Created: 2019-12-18*

A simple **bouncing ball** game written in **C++** as a mini assignment for an introductory computing course.

## Overview

A basic console game where a ball bounces on screen, demonstrating fundamentals of loops, input handling, and game-loop structure in C++.

## Features

- Simple bouncing-ball gameplay
- Console-based rendering

## Tech Stack

C++.

## Status

Completed beginner course assignment.
